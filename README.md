# Leaflet Clickable Polyline Demo

Demo app accompanying the article [Making Leaflet polylines easier to click on mobile](https://www.curtiscode.dev/post/making-leaflet-polylines-easier-to-click-on-mobile), demonstrating how to widen the hit area of a Leaflet polyline using a transparent overlay.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
